# Rota Alternativa

🗺️📍 O Rota Alternativa foi um projeto criado pela classe de 1TW, com o objetivo de criar um site para dar espaço a áreas de trabalho que não são muito comuns e assim são ignoradas pelas pessoas, 
então tivemos essa proposta na ideia de dar um olhar novo para os jovens que estão entrando na área de trabalho e querem descobrir novas possibilidades para o futuro.

📖🎯 Usamos 3 tipos de linguagens e tecnologias para sua criação:
HTML5: estruturação e organização das páginas;
CSS3: estilização, identidade visual, layouts e responsividade;
Bootstrap 5.3: utilizado para auxiliar na construção do layout e na responsividade do site;
Além do uso de IA para a criação inicial do design e estrutura do trabalho.
