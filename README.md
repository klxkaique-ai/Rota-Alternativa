# Rota Alternativa

O **Rota Alternativa** é um projeto desenvolvido pela turma **1TW** com o objetivo de dar visibilidade a áreas de trabalho pouco convencionais que costumam passar despercebidas. A proposta busca oferecer um novo olhar para jovens que estão ingressando no mercado de trabalho e desejam descobrir possibilidades diferentes para o futuro profissional.

## Tecnologias Utilizadas

* **HTML5:** Estruturação e organização semântica das páginas.
* **CSS3:** Estilização, identidade visual, layouts e responsividade.
* **Bootstrap 5.3:** Auxílio na construção do layout e na responsividade do `index.html`.
* **Inteligência Artificial:** Utilizada como suporte na criação inicial do design e da estrutura do projeto.
